01 / About

A SHARED COURSE
OF ENGINEERING.

ELECOURSE is a student-led engineering research community where students from different fields learn, design, and build engineering systems together.

Every semester, members form interdisciplinary teams to develop complete engineering systems covering hardware, embedded systems, signal processing, FPGA, machine learning, and experimental validation.

2026 / Fall

FPGA-Based
Battery
Management
System

An FPGA-based BMS platform that monitors lithium-ion battery conditions in real time and estimates SOC and SOH using STM32 and FPGA.

  • Hardware Design — AFE + STM32
  • FPGA Accelerator
  • Signal Processing Pipeline
  • SOC / SOH Estimation
  • Machine Learning Prediction
  • Performance Evaluation
2026 / Spring

Cuffless
Blood Pressure
Estimation

An end-to-end blood pressure estimation system based on synchronized ECG and PPG signals.

  • STM32 + AD8232 + MAX30102
  • Signal Acquisition
  • Signal Processing
  • PAT / PTT Feature Extraction
  • Machine Learning Prediction
  • Validation
